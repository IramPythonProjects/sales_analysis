# sales_analysis
# E-Commerce Sales Analysis Dashboard 📊

A complete sales analysis dashboard built with Python Matplotlib.
It shows 6 different visualizations in one dashboard using fixed data.

## Features
- Monthly Sales Trend (Line Plot)
- Sales by Category (Bar Plot)
- Category Share (Pie Chart)
- Sales vs Profit Relation (Scatter Plot)
- Customer Age Distribution (Histogram)
- Top 5 Sales Months (Horizontal Bar Plot)

## Technologies Used
- Python
- Matplotlib

## How to Run
pip install -r requirements.txt
python main.py

## Output
This will generate `dashboard.png` - a complete 6-chart dashboard.
